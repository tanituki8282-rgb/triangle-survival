# Triangle Survival（トライアングルサバイバル）

ブラウザで遊べるヴァンパイアサバイバー系・全方位2Dシューティング。
三角形の自機を動かし、群れをなぎ倒し、弾幕をかわし、強化を積み、ボスを討つ。

依存ゼロの静的サイト（`index.html` + ES modules + Canvas 2D + Web Audio）。

## Play

GitHub Pages（リポジトリ Settings → Pages で GitHub Actions、または `main` のルートを公開）:

```
https://tanituki8282-rgb.github.io/triangle-survival/
```

ローカル:

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開く。ES modules のため `file://` では動きません。

## 操作

| 入力 | 動作 |
| --- | --- |
| WASD / 矢印 | 移動 |
| （自動） | 最寄りの敵へ自動射撃 |
| 1 / 2 / 3 またはクリック | レベルアップ強化を選択 |
| P / Esc | ポーズ |
| M | ミュート |
| Enter / Space | タイトルから開始 |
| Enter / R | リザルトから再出撃 |

## 遊び方

1. START で出撃。敵を撃破すると緑の経験値が飛び、レベルアップで3択の強化が入る（RANK と数値がカードに出る）。
2. 雑魚は円・菱形・六角・四角・突進三角。敵弾は赤〜橙の白芯。突進は橙、ジェムは緑。
3. 約 105 秒で **プリズムオーバーロード** が出現（数秒の余白あり）。撃破後に短い余韻、被弾し切ると機体喪失。
4. 連射・拡散・貫通・衛星刃・ノヴァなどで「なぎ倒し」が伸びる。

検証用: `?debug=1` で FPS、`?boss=1` で即ボス、`?god=1` で無敵。
