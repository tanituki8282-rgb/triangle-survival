# Triangle Survival（トライアングルサバイバル）

ブラウザで遊べるヴァンパイアサバイバー系・全方位2Dシューティング実験。
Grok Bot チームが役割分担して自律開発する検証用プロジェクト。

## Play
（実装後）GitHub Pages または `index.html` をブラウザで開く。

## Spec
- `トライアングルサバイバル.md` — 元仕様
- `INTERPRETATION.md` — エメラルド解釈・スコープ
- `TASKS.md` — 進捗
